# AutoFlowMate action reference

Generated by `autoflow docs`. Every step is a JSON object with `"action"` plus the fields below.
All fields are optional in JSON (defaults shown in the template), but `autoflow validate` reports required ones.
String fields support `${variable}` interpolation.

Common step fields: `id`, `enabled` (default true), `comment`, `on_error` (`stop`|`continue`), `retries`, `retry_delay_ms` (default 1000).

## Flow

### `set_variable`

Set a variable (strings are interpolated).

| field | default | description |
|---|---|---|
| `name` | `""` | Variable name (without `${}`). |
| `value` | `null` | Value. Strings are interpolated; a string that is exactly `${x}` copies x's value as-is (lists stay lists). Numbers, bools, arrays and objects are stored as given. |

```json
{"action":"set_variable","name":"","value":null}
```

### `increment`

Add a number to a numeric variable (counters).

| field | default | description |
|---|---|---|
| `name` | `""` | Numeric variable to change (missing = 0). |
| `by` | `1` | Amount to add (negative to subtract). |

```json
{"action":"increment","name":"","by":1}
```

### `log`

Write a message to the run log.

| field | default | description |
|---|---|---|
| `message` | `""` | Text to log (interpolated). |
| `level` | `"info"` | info, warn or error. |

```json
{"action":"log","message":"","level":"info"}
```

### `wait`

Pause for a number of milliseconds.

| field | default | description |
|---|---|---|
| `ms` | `1000` | Milliseconds to wait. |

```json
{"action":"wait","ms":1000}
```

### `if`

Run `then` steps if the condition holds, otherwise `else` steps.

| field | default | description |
|---|---|---|
| `condition` | `{"left":"","op":"equals","right":"","ignore_case":false}` | The test: {left, op, right}. |
| `then` | `[]` | Steps run when the condition is true. |
| `else` | `[]` | Steps run when the condition is false. |

```json
{"action":"if","condition":{"left":"","op":"equals","right":"","ignore_case":false},"then":[],"else":[]}
```

### `repeat`

Run `steps` a fixed number of times.

| field | default | description |
|---|---|---|
| `times` | `3` | Number of iterations. |
| `index_var` | `"index"` | Variable holding the 0-based iteration number. |
| `steps` | `[]` | Steps run each iteration. |

```json
{"action":"repeat","times":3,"index_var":"index","steps":[]}
```

### `while`

Run `steps` while the condition holds (bounded by max_iterations).

| field | default | description |
|---|---|---|
| `condition` | `{"left":"","op":"equals","right":"","ignore_case":false}` | Loop while this is true (checked before each iteration). |
| `max_iterations` | `1000` | Safety limit; the step fails when reached. |
| `steps` | `[]` | Steps run each iteration. |

```json
{"action":"while","condition":{"left":"","op":"equals","right":"","ignore_case":false},"max_iterations":1000,"steps":[]}
```

### `for_each`

Run `steps` once per item of a list.

| field | default | description |
|---|---|---|
| `items` | `""` | A JSON array, or a string: `${list_var}` (an array variable) or text that is split into lines. |
| `item_var` | `"item"` | Variable holding the current item. |
| `index_var` | `"index"` | Variable holding the 0-based position. |
| `steps` | `[]` | Steps run for each item. |

```json
{"action":"for_each","items":"","item_var":"item","index_var":"index","steps":[]}
```

### `break`

Leave the innermost repeat / while / for_each loop.

```json
{"action":"break"}
```

### `stop`

End the flow now, successfully or as a failure.

| field | default | description |
|---|---|---|
| `message` | `""` | Final message of the run. |
| `success` | `true` | true = finish the flow successfully, false = fail it. |

```json
{"action":"stop","message":"","success":true}
```

### `run_flow`

Run another flow file as a sub-flow.

| field | default | description |
|---|---|---|
| `path` | `""` | Path of another flow JSON file (relative paths resolve against this flow's folder). |
| `variables` | `{}` | Variables passed to the sub-flow (values interpolated). |
| `share_variables` | `false` | If true, variables set by the sub-flow are copied back into this flow. |

```json
{"action":"run_flow","path":"","variables":{},"share_variables":false}
```

### `try`

Run steps; on failure run `catch` instead of stopping; always run `finally`.

| field | default | description |
|---|---|---|
| `steps` | `[]` | Steps to try. |
| `catch` | `[]` | Steps run when one of `steps` fails (the error text is in error_var). |
| `finally` | `[]` | Steps run afterwards in every case (e.g. close the browser or the program). |
| `error_var` | `"error"` | Variable receiving the error message (it names the step that failed). |

```json
{"action":"try","steps":[],"catch":[],"finally":[],"error_var":"error"}
```

## Data

### `read_excel`

Read a sheet (or one column) of an Excel workbook into a list variable.

| field | default | description |
|---|---|---|
| `path` | `""` | Workbook file (.xlsx, .xlsm, .xls, .xlsb, .ods). |
| `sheet` | `""` | Sheet name; empty = the first sheet. |
| `range` | `""` | Only this cell range, e.g. `A1:D50`; empty = the whole used area. |
| `has_header` | `true` | The first row holds column names. |
| `column` | `""` | Return only this column as a list: header name (e.g. `GSTIN`), letter (`B`) or number (`2`). Empty = all columns. |
| `skip_empty` | `true` | Leave out empty rows (and empty cells when reading one column). |
| `output_var` | `"rows"` | Variable receiving the data: a list of values (column), of records {header: value}, or of rows. |
| `count_var` | `""` | Variable receiving the number of rows (optional). |

```json
{"action":"read_excel","path":"","sheet":"","range":"","has_header":true,"column":"","skip_empty":true,"output_var":"rows","count_var":""}
```

Write a list of records to a CSV file (Excel-friendly).

| field | default | description |

## Text

### `text_transform`

| field | default | description |
|---|---|---|
| `input` | `""` | The text (interpolated). |

| `replace_with` | `""` | Replacement. With regex, $1 / ${name} insert captured groups. |

### `text_extract`

Pick out text with a regular expression (first match or all).

| field | default | description |
|---|---|---|
| `input` | `""` | The text to search (interpolated), e.g. "${pdf_text}". |
| `pattern` | `""` | Regular expression, e.g. "Invoice No[.:]\\s*(\\S+)" or "\\d{2}[A-Z]{5}\\d{4}[A-Z]\\d[Z][A-Z\\d]" (GSTIN). |


## Date & Math

| field | default | description |
|---|---|---|

| `output_var` | `"date"` | Variable receiving the result. |

```json
{"action":"date_calc","operation":"format","date":"","input_format":"","amount":0,"unit":"days","other_date":"","format":"dd-MM-yyyy","output_var":"date"}
```

## Internet

### `http_request`

| field | default | description |
|---|---|---|
| `method` | `"GET"` | GET, POST, PUT, PATCH, DELETE or HEAD. |

| `status_var` | `""` | Variable receiving the HTTP status code (optional). |

```json
{"action":"http_request","method":"GET","url":"","headers":{},"body":"","bearer_secret":"","save_to":"","fail_on_error_status":true,"parse_json":true,"timeout_ms":60000,"output_var":"response","status_var":""}
```

## AI

### `ai_prompt`

Ask a local (LM Studio, Ollama) or cloud (OpenAI, Gemini, Claude) AI model; optionally force one of given labels.

| field | default | description |
|---|---|---|
| `provider` | `"lmstudio"` | lmstudio (local, default), ollama (local), openai_compatible, openai, gemini or anthropic. |
| `model` | `""` | Model name. Empty = the model loaded in LM Studio/Ollama, or a default for cloud providers. |
| `base_url` | `""` | Server address; empty = the provider's default (LM Studio: http://localhost:1234/v1). |
| `api_key_secret` | `""` | Name of the API key stored with `autoflow secret set NAME` (not needed for local servers). |
| `system` | `""` | Instructions for the model (interpolated), e.g. "You classify customer comments." |
| `prompt` | `""` | The prompt (interpolated), e.g. "Classify this comment: ${row.Comment}". |
| `labels` | `[]` | Allowed answers, e.g. ["Fav", "UnFav", "Neutral"]. The model is told to reply with one, and the stored value is always exactly one of them (the step fails otherwise). |
| `json` | `false` | Ask for JSON and store the parsed object (so ${reply.field} works). |
| `temperature` | `null` | Randomness, 0 = most predictable (empty = provider default; ignored by Claude). |
| `max_tokens` | `4096` | Longest reply, in tokens (thinking models need room to think). |
| `timeout_ms` | `120000` | How long to wait for the reply, in ms. |
| `output_var` | `"reply"` | Variable receiving the reply (or the label / parsed JSON). |

```json
{"action":"ai_prompt","provider":"lmstudio","model":"","base_url":"","api_key_secret":"","system":"","prompt":"","labels":[],"json":false,"temperature":null,"max_tokens":4096,"timeout_ms":120000,"output_var":"reply"}
```
