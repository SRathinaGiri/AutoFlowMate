# AutoFlowMate action reference

Generated by `autoflow docs`. Every step is a JSON object with `"action"` plus the fields below.
All fields are optional in JSON (defaults shown in the template), but `autoflow validate` reports required ones.
String fields support `${variable}` interpolation.

Common step fields: `id`, `enabled` (default true), `comment`, `on_error` (`stop`|`continue`), `retries`, `retry_delay_ms` (default 1000).

## Flow

### `set_variable`

Set a variable (strings are interpolated).

| field | default | description |
|---|---|---|
| `name` | `""` | Variable name (without `${}`). |
| `value` | `null` | Value. Strings are interpolated; a string that is exactly `${x}` copies x's value as-is (lists stay lists). Numbers, bools, arrays and objects are stored as given. |

```json
{"action":"set_variable","name":"","value":null}
```

### `increment`

Add a number to a numeric variable (counters).

| field | default | description |
|---|---|---|
| `name` | `""` | Numeric variable to change (missing = 0). |
| `by` | `1` | Amount to add (negative to subtract). |

```json
{"action":"increment","name":"","by":1}
```

### `log`

Write a message to the run log.

| field | default | description |
|---|---|---|
| `message` | `""` | Text to log (interpolated). |
| `level` | `"info"` | info, warn or error. |

```json
{"action":"log","message":"","level":"info"}
```

### `wait`

Pause for a number of milliseconds.

| field | default | description |
|---|---|---|
| `ms` | `1000` | Milliseconds to wait. |

```json
{"action":"wait","ms":1000}
```

### `if`

Run `then` steps if the condition holds, otherwise `else` steps.

| field | default | description |
|---|---|---|
| `condition` | `{"left":"","op":"equals","right":"","ignore_case":false}` | The test: {left, op, right}. |
| `then` | `[]` | Steps run when the condition is true. |
| `else` | `[]` | Steps run when the condition is false. |

```json
{"action":"if","condition":{"left":"","op":"equals","right":"","ignore_case":false},"then":[],"else":[]}
```

### `repeat`

Run `steps` a fixed number of times.

| field | default | description |
|---|---|---|
| `times` | `3` | Number of iterations. |
| `index_var` | `"index"` | Variable holding the 0-based iteration number. |
| `steps` | `[]` | Steps run each iteration. |

```json
{"action":"repeat","times":3,"index_var":"index","steps":[]}
```

### `while`

Run `steps` while the condition holds (bounded by max_iterations).

| field | default | description |
|---|---|---|
| `condition` | `{"left":"","op":"equals","right":"","ignore_case":false}` | Loop while this is true (checked before each iteration). |
| `max_iterations` | `1000` | Safety limit; the step fails when reached. |
| `steps` | `[]` | Steps run each iteration. |

```json
{"action":"while","condition":{"left":"","op":"equals","right":"","ignore_case":false},"max_iterations":1000,"steps":[]}
```

### `for_each`

Run `steps` once per item of a list.

| field | default | description |
|---|---|---|
| `items` | `""` | A JSON array, or a string: `${list_var}` (an array variable) or text that is split into lines. |
| `item_var` | `"item"` | Variable holding the current item. |
| `index_var` | `"index"` | Variable holding the 0-based position. |
| `steps` | `[]` | Steps run for each item. |

```json
{"action":"for_each","items":"","item_var":"item","index_var":"index","steps":[]}
```

### `break`

Leave the innermost repeat / while / for_each loop.

```json
{"action":"break"}
```

### `stop`

End the flow now, successfully or as a failure.

| field | default | description |
|---|---|---|
| `message` | `""` | Final message of the run. |
| `success` | `true` | true = finish the flow successfully, false = fail it. |

```json
{"action":"stop","message":"","success":true}
```

### `run_flow`

Run another flow file as a sub-flow.

| field | default | description |
|---|---|---|
| `path` | `""` | Path of another flow JSON file (relative paths resolve against this flow's folder). |
| `variables` | `{}` | Variables passed to the sub-flow (values interpolated). |
| `share_variables` | `false` | If true, variables set by the sub-flow are copied back into this flow. |

```json
{"action":"run_flow","path":"","variables":{},"share_variables":false}
```

| `overwrite` | `false` | Replace existing files instead of failing. |

## Program

### `run_program`

Start a program, optionally waiting and capturing its output.

| field | default | description |
|---|---|---|
| `program` | `""` | Executable path or name on PATH (e.g. `notepad.exe`). |
| `args` | `[]` | Command-line arguments, one per item (interpolated). |
| `working_dir` | `""` | Folder to start in (empty = current). |
| `wait` | `false` | Wait for the program to exit. |
| `timeout_ms` | `0` | When waiting: fail after this many ms (0 = no limit). |
| `output_var` | `""` | When waiting: variable receiving stdout. |
| `exit_code_var` | `""` | When waiting: variable receiving the exit code. |
| `check_exit_code` | `false` | When waiting: fail if the exit code is not 0. |

```json
{"action":"run_program","program":"","args":[],"working_dir":"","wait":false,"timeout_ms":0,"output_var":"","exit_code_var":"","check_exit_code":false}
```

Click (optionally at a position).

| field | default | description |
|---|---|---|
| `x` | `null` | Screen X; omit (null) to click at the current position. |
| `y` | `null` | Screen Y; omit (null) to click at the current position. |

## UI Element

### `ui_click`

Find a UI element (UI Automation) and click it.

| field | default | description |
|---|---|---|
| `window` | `""` | Restrict the search to the top-level window whose title contains this. |
| `name` | `""` | Element name (the text a screen reader would say). |
| `name_contains` | `false` | Match when the name contains `name` instead of equalling it. |
| `automation_id` | `""` | UIA AutomationId (most stable; prefer it when present). |
| `class_name` | `""` | Win32/UIA class name, e.g. `Edit`, `Button`. |
| `control_type` | `""` | UIA control type, e.g. `Button`, `Edit`, `Document`, `MenuItem`, `ListItem`, `CheckBox`. |
| `timeout_ms` | `10000` | How long to keep searching, in ms. |
| `invoke` | `false` | Prefer the UIA Invoke pattern (works on hidden/covered controls) and fall back to a real mouse click. |
| `double` | `false` | Double-click (always a real mouse double-click). |

```json
{"action":"ui_click","window":"","name":"","name_contains":false,"automation_id":"","class_name":"","control_type":"","timeout_ms":10000,"invoke":false,"double":false}
```
